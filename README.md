# TrailMate Task List

A simple Android hiking-preparation checklist app built for my research milestone.

We also learned Java can be used instead of Kotlin

## Features

- Add custom hiking tasks
- Mark tasks complete
- View checklist progress
- Hide or show completed tasks
- Delete tasks
- Load a starter day-hike checklist

## Technology Used

- Kotlin
- Jetpack Compose
- Material 3
- Gradle
- Android Studio

## Run the App

1. Open the project in Android Studio.
2. Allow Gradle to sync.
3. Start an Android emulator or connect an Android device.
4. Click **Run**.

This project was created as an individual research project to learn Android development with Kotlin and Jetpack Compose.
